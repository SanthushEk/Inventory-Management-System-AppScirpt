# Inventory Management System

This project was built by **watching YouTube tutorials** for **learning purposes**.  
The goal was to understand how a production-like system can be created using **Google Apps Script**.

## Features
- Manage inventory items and stock records
- Add, edit, and delete inventory entries
- Simple and easy-to-use interface

## Technologies Used
- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript
